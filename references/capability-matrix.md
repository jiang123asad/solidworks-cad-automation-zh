# 能力边界与兼容性

## 统一入口与状态

1.4.1 提供 `cad_assistant.py` 与中文菜单统一调用既有工具，能力清单见 [capabilities.json](../capabilities.json)。本地能力的“已实测”对应历史 SW2026 SP1.1 脚本；新入口已完成本轮实机工作流测试。扩展工程图 CLI 已打通基础三视图与 PDF，仍为部分通过，不计作完整生产出图能力，见 [本轮实测](live-validation-1.4.1.md)。

## 当前包实际提供的支持

| 任务 | 支持范围 | 限制与证据 |
|---|---|---|
| 打开文档 | 自动识别 SLDPRT / SLDASM / SLDDRW；支持配置参数 | 需要本机 SW；错误和警告位须读取 |
| 几何检查 | 零件全部实体、面、圆边、圆柱、锥面、特征树 | 零件主配置；包围盒是粗筛值 |
| 装配体/工程图 | 打开和特征树 | 未实现组件变换/轻化解析、工程图标注遍历 |
| 渲染 | 零件/装配体标准视图截图 | BMP→PNG，不是照片级渲染；不改源文件 |
| 倒角 | 同轴且与 XYZ 轴对齐的零件，两端外圆边 | 副本、每步重取拓扑、总体积减少、保存回读 |
| 密封锥 | 单实体、轴对齐、指定端面及宽度/半角 | 中文标准平面且平面包含轴；偏置或多轴件拒绝 |
| 目录对比 | SLDPRT 按相对路径配对；总体积/面数/包围盒/特征类型和名 | 仅指标初筛；装配体列为 UNSUPPORTED，不冒充几何相同 |
| 中性导出 | STEP / Parasolid / IGES；零件/装配体 | 使用当前会话导出首选项，未自动回读导出结果 |
| 高级验证样例 | `extended_selftest.py` 11 项；实体复制、镜像、加厚、拔模、阵列、孔向导、筋、材料/颜色和干涉 | 固定教学几何；不是通用生产建模器；本机实测见运行验证 |
| 自检 | 连接/类型库/新文档，或草图/拉伸/切除等少量测试 | 不等于“48 项 API 认证”；需要显式运行 |

## API 实测与工具支持的区别

本次在 SW2026 SP1.1 独立复现了多项原包未调通的功能，包括线性/圆周实体阵列、镜像、独立拔模、筋、孔向导、曲面加厚、草图圆角/倒角和 ModifyDefinition。对应选择 Mark、FeatureData 参数见 [已验证调用要点](extended-api-recipes.md)。旧的 FeatureLinearPattern4 崩溃路径没有重放，采用 FeatureData 创建阵列。

测试证明给定样例的调用可用，不意味着 inspect/compare 等零件工具已获得完整装配体或工程图适配。1.3.0 又验证了实体螺纹、标准/高级/机械配合、爆炸、剖视/局部/辅助视图、BOM/气泡、尺寸导入、尺寸公差、几何公差及焊接符号。孔表原生数据通过但 PDF 未通过，皮带长度通过但联动未通过。基础 Simulation 静力求解和结果回读通过；Motion、Flow、CAM、Routing、PDM 等模块未做计算测试，许可证也未逐模块确认。具体参数和验收限制见 [专项实测调用](threads-mates-drawings-simulation.md)。这些新项目是参考配方，不是新增的通用 CLI。

## 旧版本交付

先确定接收版本和是否需要保留可编辑特征树。部分较新 SW 版本具备向前两版保存功能，受版本、许可与特征兼容性限制；查当前官方帮助并在副本上验证，普通 `SaveAs` 传年份不能代替该流程。

需要中性格式时：Parasolid 需确认接收方支持的内核格式版本；STEP 需确认 AP203/AP214/AP242、单位、颜色与装配结构需求。中性格式通常不保留原生参数特征历史。脚本不会自动修改全局导出首选项，若任务需临时修改，先记录旧值并在 `finally` 恢复。不能把“文件导出成功”当成“旧版已验证可打开”。
