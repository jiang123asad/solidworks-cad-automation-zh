# 工程图：视图、表格、尺寸与符号

以下来自 SW2026 SP1.1 的样件实测。先核对当前机器的接口、模板与许可；通过范围和限制见 [运行验证](runtime-validation.md)。保存与绑定问题见 [API 排错](api-pitfalls.md)。

## 视图、表格与符号

| 功能 | 本轮调用与检查 |
|---|---|
| 剖视 | 选择剖切草图线，再 `CreateSectionViewAt5`，回读视图类型 2 |
| 局部放大 | 草图圆作边界，`CreateDetailViewAt4`，类型 3、比例 2 |
| 辅助视图 | 选择可见参考边，`CreateAuxiliaryViewAt2`，类型 5 |
| BOM / 气泡 | 装配视图 `InsertBomTable4`；`CreateBalloonOptions` / `InsertBOMBalloon2`；核对数量与项目号 |
| 孔表 | 选择图中原点参考 Mark 1、孔所在面 Mark 2，选择数据绑定 View；`InsertHoleTable3`；核对坐标原点、标签、孔径和贯穿/深度 |

本机视图名使用 `*前视` / `*右视` 等本地化名称；读取当前环境或使用支持的视图枚举，不把这些字符串当跨语言常量。

### 尺寸导入与策略

`InsertModelAnnotations3` 返回空数组时，先检查源模型是否有可导出的尺寸、是否被标记、导入范围及视图方向。本轮只有正视图时拉伸深度导入为 0，加入右视图后用类型位 `32768 | 524288` 成功导入 1 个；这只解决该样例。

出图先按功能和检验方式选择尺寸，不等同于“导入所有模型尺寸”：

1. 确定基准和主要加工/装配面，选择能清楚表达结构的主视、剖视、局部和辅助视图。
2. 列出外形、厚度、孔/槽尺寸与位置、螺纹、配合及装配接口。孔坐标优先同一基准的基线/坐标尺寸；闭合尺寸链中的参考尺寸应按标准标识，避免重复控制。
3. 根据真实设计要求给出尺寸公差、配合、形位公差及基准系统；通用公差不替代关键接口要求。不要凭示例自动给所有尺寸套 ±0.2 或平面度。
4. 直径、半径、沉孔/锪孔、深度、贯穿、数量、中心线/中心标记要与几何一致；孔表和独立尺寸不得矛盾。
5. 统一图纸/视图比例，特殊比例单独标明；检查单位、投影法、材料、表面要求、标题栏和适用标准。
6. 遍历尺寸数值与容差，检查悬空引用，再看实际 PDF 的箭头、符号、文字、重叠和表格完整性，最后关闭重开原生文件。

本轮 60×40×15 mm 两孔板创建并回读了 8 个尺寸：60、40、15 厚、Ø6、Ø8、X=15/45、Y=20；60 的容差为 +0.20/-0.10 mm。它是尺寸 API 样例。模板标题栏 2:1 与视图 1:1 不一致、第二孔同 Y 位置依赖说明而非完整几何表达，仍需修正才能用于生产。

### 公差与符号

- 尺寸容差：`IDimensionTolerance.Type=2`，本轮 `SetValues(-0.0001,0.0002)`。验证下上偏差、显示精度和渲染；不要只读 Type。
- 几何公差：`InsertGtol`、`SetFrameSymbols2(1,'<IGTOL-FLAT>',...)`、`SetFrameValues2(1,'0.05',...)`、`ConvertFormat(0)`。`SetFrameSymbols2` 返回 void，不能 `assert`；读取 Frame XML 和 PDF。平面度应指向受控表面；本轮符号演示附在孔边，不能当合格制造标注。
- 焊接：`IWeldSymbol.SetText` 的填角符号使用完整 token `<WELD-FILL>`。裸 `FILL` 可返回 true 且能读回，却没有正确三角图形。`GetTriangleCount/GetTextCount` 在本机返回 0，也不能单独作图形存在性判据。必须看渲染，并按标准核对箭头侧、另一侧、焊脚/有效厚度、长度/间距等语义。
