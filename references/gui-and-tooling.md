# GUI 协同

API 用于精确几何、预选和结果测量；桌面工具用于确认界面状态和填写特征面板。使用宿主已提供且允许的桌面工具，遵守该工具的观察和输入约定。不要为了使用本 skill 自动安装 MCP、改 hosts、停用遥测或更改系统/宿主配置。

旧 `gui_helper.shot()` 截取整个主屏幕，可能包含其他窗口或通知；`confirm/cancel` 自动截图也有相同范围。运行与分享图像的边界见 [隐私说明](../PRIVACY.md)。

## 操作顺序

1. 查看当前 SW 窗口、活动文档和正在编辑的特征；只对本任务文档操作。
2. 确认 API 参数、接口与几何问题已定位，决定通过当前版本 API 修复还是用 GUI。
3. API 预选种子、方向、轴或面，Mark 取当前操作定义；不能通用套用一个 Mark 表。
4. 用当前截图/可访问树打开对应命令并填写数值。菜单助记符因版本和语言变化；原包中文环境的 `Alt` 松开后 `I→E→L/C/M` 仅作线性阵列/圆周阵列/镜像的候选。
5. 确认活动输入框、单位、实例数、方向和预览。选取多个类别时按面板焦点分别填入，不能假设 API 预选全部被保留。
6. 观察明确的确认按钮后提交，重新观察面板关闭和模型变化，再 API 重建、测量目标与保存回读。

## 坐标和按钮

截图和鼠标 API 的坐标域受 DPI 感知、缩放和多显示器影响，先根据当前工具文档与截图验证，不固定乘系数。截图缩放后要按真实坐标映射；负坐标显示器也需考虑。

`gui_helper.py` 是保留给非受限宿主的低层辅助库。颜色定位仅提供候选坐标，不是确认操作依据；默认 `confirm/cancel` 不点击，须观察候选确为目标后显式传 `click_candidate=True`。不要合并分散绿色像素的中位数后盲点。窗口未置前、多个 SW 窗口或按钮不明确时停止输入，重新观察。

Win32 鼠标键盘只在宿主允许时使用；若宿主已有专用桌面自动化工具，优先该工具。Windows-MCP、WorkBuddy 专有 PDF/Word 工具都不是依赖；PDF 图纸使用当前环境可用的 PDF 工具，图纸标注不能靠查找某个字母推断。

## 结果与恢复

点击返回只代表已发出输入。验证面板实际关闭、目标特征出现且局部几何达标。每次有根据地修正一个因素，至多两次；不要自动发 Enter 反复接受未知对话框。SW 崩溃或焦点异常时停止本批，保留日志和已完成输出，不关闭其他任务文档或强杀进程。
